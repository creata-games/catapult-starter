# Катапульта — старт к теме 1

Это твой пустой проект практикума Creata Academy: Unity 6000.3.26f1, 2D URP, Input System и Pixel Perfect. В `Assets/Scenes/Main.unity` есть только настроенная камера. Механики, уровни, план игры и игровые ассеты ты создашь по теме 1.

Начни с [kit/README.md](kit/README.md): там подготовка на Windows и macOS, открытие через Unity Hub и проверка локальной связи с Claude Code. **До первого открытия Unity выполни подготовку из раздела 2**: она задаёт Custom вместо облачного режима плагина.

Правила помощника — [CLAUDE.md](CLAUDE.md); `AGENTS.md` направляет к тому же файлу. Журналы уже созданы, но заполняешь их ты. `PLAN.md` появится после согласования твоего плана с помощником.

Готовая игра: https://play.creata.games/game?id=catapult
