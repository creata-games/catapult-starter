# Catapult — starter project (topic 1)

An empty, pre-configured Unity project for the «Catapult» practicum of GameDev School, Creata Academy: Unity 6000.3.26f1, 2D URP, Input System, Pixel Perfect. `Assets/Scenes/Main.unity` is an empty scene with a Pixel Perfect camera (480×270, 16 PPU).

- Setup on Windows and macOS, opening in Unity Hub and connecting the assistant: [kit/README.md](kit/README.md) (Russian).
- Assistant rules: [CLAUDE.md](CLAUDE.md); the assistant bridge (AI Game Developer, Custom mode) runs locally at `http://localhost:9048` — no keys in this repository.
- Play the finished game: https://play.creata.games/game?id=catapult
